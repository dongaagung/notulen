# Notulen

A native macOS app that records a meeting from start to end, transcribes it
on your Mac, and writes the minutes: a summary of each topic discussed,
decisions, action items and open questions.

*Notulen* is Indonesian for meeting minutes.

## Status

Early design. Built on the same stack as
[interview-assistant](https://github.com/dongaagung/interview-assistant):
Swift and SwiftUI, Core Audio process taps for meeting audio, the Speech
framework for on-device transcription, and an AI provider (Claude by default)
for the minutes.
