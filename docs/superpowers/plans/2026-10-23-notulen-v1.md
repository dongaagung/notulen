# Notulen v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App macOS yang merekam meeting online, mentranskripsikannya di Mac,
menampilkan catatan sementara selama meeting, lalu memisahkan pembicara dan
menulis notulen terstruktur dalam Bahasa Indonesia, dengan ekspor ke Markdown,
PDF, Notion, dan terjemahan.

**Architecture:**
- Satu target SwiftPM bernama `Notulen` (folder `App/`), dengan struktur yang
  mengikuti interview-assistant. Kode dari sana disalin lalu disesuaikan, bukan
  ditautkan.
- **Alur rekam**: audio app meeting dan mic → SpeechAnalyzer → `Transcript` →
  `TranscriptJournal` (append + fsync).
- **Jalur meeting** juga ditahan di RAM (`MeetingAudioBuffer`) untuk diarisasi
  FluidAudio setelah meeting selesai.
- **AI**: catatan sementara memakai fast model. Notulen dan terjemahan memakai
  smart model. Semua balasan AI berupa JSON terstruktur.
- **Pekerjaan dibagi enam fase.** Setiap fase berakhir dengan app yang jalan.

**Tech Stack:**
- Swift 6.2+ dan SwiftUI (macOS 26).
- Core Audio process tap, AVAudioEngine, Speech (SpeechAnalyzer, dengan
  DictationTranscriber untuk id-ID).
- FluidAudio 0.17.7 (diarisasi offline).
- Anthropic Messages API lewat URLSession, Notion API, WebKit (PDF).
- Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-22-notulen-design.md`. Baca bersama
plan ini. Mockup UI ada di
`.superpowers/brainstorm/84454-1792679965/content/live-layout-apple-v2.html`
dan `final-notes.html`. Folder itu lokal dan diabaikan git, tapi ada di mesin
ini.

## Global Constraints

- **Build dan target**:
  - Build hanya dengan Command Line Tools + SwiftPM, memakai
    `--build-system native`.
  - `swift-tools-version: 6.2`, `platforms: [.macOS(.v26)]`, dan
    `LSMinimumSystemVersion` `26.0`.
- **Tidak ada alat khusus Xcode**:
  - Tidak ada `#Preview`, asset catalog, makro SwiftData, atau `@Entry`.
  - Pakai `@ViewState`, bukan `@State`.
  - `EnvironmentKey` ditulis manual.
- **Identitas app**:
  - Nama app `Notulen`, executable `Notulen`.
  - Bundle ID `rakyat.notulen`, terpasang di `/Applications/Notulen.app`.
  - Data di `~/Library/Application Support/rakyat.notulen`, dan service
    Keychain `rakyat.notulen`.
- **Model AI**:
  - `claude-haiku-5-5` untuk catatan sementara.
  - `claude-sonnet-5-5` untuk notulen dan terjemahan.
  - Provider lain: fast model untuk catatan sementara, smart model untuk
    sisanya.
- **Audio**:
  - Audio mentah tidak pernah ditulis ke disk.
  - Jangan pernah panggil FluidAudio `process(_ url:)`,
    `makeDiskBackedSource`, atau `prepareModels`.
  - `embeddingExportPath` tetap `nil`. Embedding tidak disimpan.
- **FluidAudio**:
  - `.package(url: "https://github.com/FluidInference/FluidAudio.git", exact: "0.17.7", traits: [])`.
  - Model diambil dari `FluidInference/speaker-diarization-coreml`, revisi
    `df2625ac79a7ac6b65ad868fee6d80f320da4232`.
  - Set `ModelHub.offlineMode = true` sebelum model dimuat.
- **Kunci** (provider AI dan Notion) hanya di Keychain.
- **Notulen dan UI**:
  - Notulen selalu dalam Bahasa Indonesia, dan `owner`/`due` bernilai `null`
    kalau tidak disebut.
  - Teks UI dalam Bahasa Indonesia.
  - Satu warna aksen (biru sistem). Merah hanya untuk penanda rekaman.
- **Ambang waktu**:
  - Tidur > 15 menit membuat app bertanya dulu.
  - Sunyi 10 menit, atau app meeting ditutup, memunculkan tawaran Selesai.
  - Catatan sementara diperbarui sekitar setiap 150 detik.
  - Buffer audio meeting maksimal 4 jam.
- **Notion**: header `Notion-Version: 2026-03-11`.
- **Prompt** disimpan di `prompts/*.md` dengan `{{variabel}}`, dimuat oleh
  `PromptTemplate`.

## Review Focus

1. **Meeting lebih dari 1 jam.** Semua penanda waktu (transkrip, input AI,
   notulen, Markdown, PDF, Notion) harus `1:15:14`, bukan `75:14`. Diuji di
   Task 2 dan Task 13.
2. **Selesai pada meeting tanpa percakapan.** Contohnya meeting yang baru
   dimulai lalu langsung dihentikan, atau sunyi. Hasilnya: tidak ada panggilan
   AI, meeting berstatus siap dengan teks "Tidak ada percakapan yang terekam.",
   dan diarisasi dilewati tanpa error. Diuji di Task 16, 17, dan 20.
3. **JSON dari AI berisi rujukan aneh**: token `[[s9]]` yang tidak dikenal,
   `at` melewati durasi, atau field opsional yang hilang. App harus tetap
   menampilkan "Lainnya", menjepit waktu ke durasi meeting, dan tidak crash.
   Diuji di Task 13 dan 16.
4. **Teks panjang ke Notion**: lebih dari 2000 karakter per teks, atau lebih
   dari 100 blok. Teks harus dipecah dan blok dikirim per batch, bukan ditolak
   API. Diuji di Task 25.
5. **Memulai meeting kedua saat satu masih merekam**, atau memilih app meeting
   yang tidak berjalan. App harus menolak dengan pesan yang jelas. Diuji di
   Task 4 dan Task 7.

### Task 5: Buffer audio meeting di RAM

**Files:**

**Interfaces:**
- Consumes: `AVAudioFormat.mono16kInt16` (Task 4).
- Produces:
  ```swift
  /// Meeting-channel audio for diarization, in RAM only. One writer while recording; read only after recording stops.
  final class MeetingAudioBuffer: @unchecked Sendable {
      static let sampleRate = 16_000.0
      static let maxDuration: TimeInterval = 4 * 3600
      convenience init()
      init(maxSamples: Int, chunkSamples: Int)          // tests use small sizes
      func beginSegment(atMeetingTime: TimeInterval)    // after start, wake, resume
      @discardableResult func append(_ buffer: AVAudioPCMBuffer) -> Bool   // mono16kInt16; false once full (excess dropped)
      var sampleCount: Int { get }
      var coveredUntil: TimeInterval? { get }           // meeting time where stored audio ends
      func copySamples(into destination: UnsafeMutablePointer<Float>, offset: Int, count: Int) throws   // Int16 / 32768
      func meetingTime(ofBufferTime seconds: TimeInterval) -> TimeInterval
      func wipe()                                       // zero every chunk, free it; sampleCount = 0
  }
  ```
- **Penyimpanan**: potongan `UnsafeMutableBufferPointer<Int16>` sebanyak
  `chunkSamples` (default 10 menit = 9.600.000 sampel), dialokasikan sesuai
  kebutuhan. Batas default 4 jam setara 230.400.000 sampel. Bentuk
  `copySamples` dan `sampleCount` cocok dengan protokol `AudioSampleSource`
  FluidAudio. Konformansinya ditambahkan di Task 20.
